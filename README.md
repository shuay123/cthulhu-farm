Cthulhu Farming Simulator

A Lovecraftian farm-simulation game built with Godot Engine (GDScript)

Core Mechanics
- Dynamic Sanity & Event System: Weather, NPC reactions, and tile alterations triggered by sanity drop
- Dual Agriculture: Balance mundane crops with forbidden mutant flora to appease underground elder deities (e.g. Yig-Thalass)
- Procedural / Asynchronous TileMap Reconstruction

Tech Stack
- Engine: Godot 4.x
- Language: GDScript
- Architecture: Decoupled event-driven state machine via SanityEventManager.gd
